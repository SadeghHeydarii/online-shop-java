# سامانه فروشگاه آنلاین شیءگرا (Online Shop Java Implementation)

پروژه درس اصول طراحی نرم‌افزار - بخش دوم فاز اول (پیاده‌سازی در جاوا)  
دانشکده ریاضی و علوم کامپیوتر، دانشگاه صنعتی امیرکبیر (پلی‌تکنیک تهران) - پاییز ۱۴۰۵  
**مدرس:** سرکار خانم دکتر هانیه فلاح  
**سر تدریسیار:** جناب آقای امیرمحمد ذاکر  

---

## ساختار و معماری پروژه

این سامانه مطابق با الزامات رسمی درس و مدل دامنه مستندشده (`domain-model-specification.md`) بر مبنای معماری چهارلایه‌ای صریح و یکپارچه پیاده‌سازی می‌شود:

```
online-shop-implementation/
├── pom.xml                                   # پیکربندی بیلد و وابستگی‌های Maven
├── README.md                                 # مستند معرفی و راهنمای پروژه
├── .gitignore                                # قوانین نادیده‌گیری فایل‌های کامپایل و سیستمی
└── src/
    ├── main/
    │   └── java/
    │       └── org/
    │           └── example/
    │               ├── Main.java             # نقطه ورود، راه‌اندازی و تزریق وابستگی
    │               ├── cli/                  # لایه تعامل کاربری و منوهای کنسول (Presentation)
    │               ├── model/                # لایه دامنه (Entities, Value Objects, Invariants)
    │               ├── service/              # لایه هماهنگ‌کننده Use Caseها و ذخیره‌سازی درون‌حافظه‌ای
    │               └── util/                 # ابزارهای کمکی (هش پسورد، سیدر داده و ...)
    └── test/
        └── java/
            └── org/
                └── example/                  # آزمون‌های واحد و سرتاسری JUnit 5
```

## مشخصات فنی و محیط اجرا

* **زبان:** Java 21 (LTS) - OpenJDK (Eclipse Adoptium Temurin)
* **ابزار ساخت:** Apache Maven 3.9+
* **محیط توسعه:** Visual Studio Code
* **چارچوب تست:** JUnit 5 (Jupiter)


## اجرا و آزمون

ابتدا Java 21 و Maven را نصب کنید. در پوشه‌ای که `pom.xml` قرار دارد:

```bash
mvn test
mvn compile exec:java
```

## امکانات منوها

- مهمان: مشاهده، جستجو و مرتب‌سازی محصولات، جزئیات و نظرات، دسته‌بندی، ثبت‌نام، ورود و بازیابی رمز.
- مشتری: سبد خرید، ثبت سفارش، پرداخت، سابقه سفارش، نظر و امتیاز، پروفایل و افزودن/ویرایش/حذف آدرس. گزینه ۷ ابزارهای کامل کاتالوگ را باز می‌کند.
- مدیر: ایجاد، ویرایش و غیرفعال‌سازی محصول، موجودی، وضعیت سفارش، URL تصاویر و فهرست همه سفارش‌ها با فیلتر وضعیت.

بازیابی رمز و پرداخت در این نسخه شبیه‌سازی کنسولی هستند. کد بازیابی روی کنسول نشان داده می‌شود و ده دقیقه اعتبار دارد. تصاویر به شکل URL ذخیره می‌شوند. داده‌ها با بستن برنامه پاک می‌شوند.

فایل [domain-model-specification.md](domain-model-specification.md) شامل روابط و تعداد آن‌ها، قوانین دامنه، نگاشت ۳۶ داستان کاربری و مشخصات کامل کلاس‌ها است.
